## 타이포

- 한글: **Noto Sans KR** — 400 / 500 / 700
- 숫자: **Roboto** — 시각, 타이머, 날짜 셀. 타이머 시계는 `font-variant-numeric: tabular-nums`
- 화면 제목 700/26, 날짜 헤더 700/22, 행 제목 500/15·20, 메타 400/12·16, 섹션 라벨 500/11 (`letter-spacing .08em`)

## 모양

행 16dp · 카드/시트 28dp · 버튼 14~16dp · FAB 20dp(64×64) · 세션 바 24dp · 달력 셀 원형 44dp

## 화면별 구성

### 1 · Today
날짜 헤더(`‹ 9월 2일 수요일 / 오늘 · 일정 4개 ›`, 가운데 탭 → 미니 달력) → `일정` 섹션 라벨(우측에 "좌우로 스와이프") → 일정 행 → `할 일` 섹션 라벨 → 할일 행 → 하단 고정 세션 바 → FAB `＋`.

- **일정 행**: 시각(54dp 고정) · 3dp 색 막대 · 제목/메타 · 「캘린더에서 열기」 아이콘 버튼. 지난 일정은 `opacity .45`
- **할일 행**: 22dp 원형 체크 · 제목(완료 시 취소선)/메타. 완료 행은 `opacity .5`
- **세션 바**: `집중 중` 라벨 · 세션 이름 · 큰 시계 · `정지` 원형 버튼
- **미니 달력**: 월 헤더 `←/→`, 요일 머리글(일=`Sunday`, 토=`Saturday`), 7열 격자, 선택된 날은 채운 녹색 원, 오늘은 녹색 테두리, 일정 있는 날은 숫자 아래 점

### 2 · ＋ 시트
`할 일 추가` / `일정 추가` 탭 → `제목` → (`시작 시각` | `반복`) + `길이` 칩 세 개 → 힌트 한 줄 → `취소` + 저장.
기본 캘린더가 없으면 힌트가 `Sunday` 색으로 바뀌고 저장 버튼이 `설정에서 캘린더 고르기`로 바뀐다.

### 3 · 설정
`타이머` 구역 — 기본 집중 시간. `캘린더` 구역 — 일정을 추가할 캘린더(라디오 + 색 견본 + 계정명).
쓸 수 있는 캘린더가 없으면 안내 카드와 `권한 허용` 버튼.

## 조절 노브 (디자인 props)

`defaultMinutes` 5–90 (step 5, 기본 25) · `dimPastEvents` (기본 켬) · `showEventDots` (기본 켬).
앞의 둘은 앱 설정으로 들어가고, `showEventDots`는 미니 달력 점의 표시 여부다.

## 계획과 어긋나는 곳 — 디자인을 따른다

| 항목 | 계획(스펙) | 디자인 | 결정 |
|---|---|---|---|
| 현재 시각 선 | 목록 중간에 "지금" 선 | 없음. 지난 일정을 흐리게 | **디자인.** 선 하나 없애고 `dimPastEvents`로 대신한다. `DayAgenda`에서 `AgendaRow.Now`를 뺀다 |
| 종일 일정 자리 | 맨 위 별도 줄 | 시간 일정과 같은 목록, 시각 칸에 `종일` | **절충.** 한 목록에 두되 맨 위로 올린다. 디자인의 순서는 데모 데이터 순서일 뿐이고, 종일이 중간에 끼면 시간순이 깨진다 |
| 이월 배지 | 행에 "3일째" 배지 | 없음 (메타는 "25분") | **절충.** 메타 한 줄에 합친다 — `25분 · 3일째` |
| 일정 색 막대 | 캘린더 색 점 | 3dp 막대, 시간 일정은 녹색 고정 | **절충.** 막대 모양은 디자인대로, 색은 `event.color`(실제 캘린더 색)를 쓴다. 데모엔 색이 하나뿐이라 고정처럼 보이는 것이고, 설정 화면은 캘린더마다 색을 보여준다 |
| 할일 완료 | 계획엔 토글 UI 없음 | 원형 체크 | **디자인.** `doneAtEpoch`를 쓰는 토글을 Today에 넣는다 |
| 토스트 | 계획에 없음 | 하단 토스트 | **디자인.** 「캘린더에서 열기」 같은 동작의 피드백으로 쓴다 |
